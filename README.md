# 《十点十七分》 第一章《迟到》

## 在线试玩

**https://flxdbyqq.github.io/ten-seventeen/**

首次打开需要加载 Web 运行时和游戏数据（约 80 MB），请稍等。建议桌面浏览器或手机横屏。

## 怎么玩（本地）

需要 **Ren'Py 8.6.1**。本仓库不包含 `_sdk/`，用 SDK 直接运行本目录：

```
<renpy-sdk>\renpy.exe <本仓库路径>
```

如果本地保留了 `_sdk/renpy-8.6.1-sdk/`，也可以双击 `开始游戏.bat`。

## 操作

- **鼠标左键 / 回车 / 空格**：推进对话
- **右键 / Esc**：菜单
- **按住 Ctrl**：快进
- **滚轮向上**：回看

## 当前内容

第一章《迟到》完整流程，约 3–4 分钟：

黑屏冷开场 → 殡仪馆大厅 → 棺材（看 / 不看）→ 幻觉 → 标题卡 → 灵堂（抽 / 不抽）→ 案卷 → 《局外人》

## 仓库结构

- `game/` — Ren'Py 源码与游戏资源
- `docs/` — 设定、剧本、音效清单等文档
- `tools/` — 素材处理脚本
- Web 版构建发布在 `gh-pages` 分支，由 GitHub Pages 提供
- `风格/`、`音效/` 原始素材和 `docs/ui_preview/` 预览存档保留在本地，未纳入仓库
