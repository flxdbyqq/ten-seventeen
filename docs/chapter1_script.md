# 《十点十七分》
## 第一章《迟到》· 三分钟脚本 v0.1

**基调**：冷、平、荒诞。黑色幽默来自“葬礼被流程化”，不是来自嘲笑死亡。
**视角**：第一人称内心独白；画面偶尔切第三人称，莫罗的立绘只出现在幻觉和关键镜头。
**视觉规则**：人物黑白，环境黑白灰，唯一暖色是烛光；除莫罗外，所有 NPC 只有背影或剪影。
**构图规则**：主角在画面右侧，NPC 在左侧。右侧是莫罗/玩家的空间，左侧是这个世界的位置。

## 实现备注

- **不做双人同框**：莫罗是胸像，司仪是七分身，景别不一致。demo 里司仪单独在左（第一人称），莫罗只以脸部特写出现在棺材 / 幻觉；以后要双人同框，再补一张七分身莫罗。
- **变量**：`saw_body`（看 / 不看）、`smoked`（抽 / 不抽）、`coffin_seconds`（玩家在棺材画面停留的真实秒数）。
- **时间戳 UI**：右上角小号等宽字，随场景更新：10:17 → 10:23 → 10:42 → 10:47 → 10:58 → 11:03。
- **幻觉叠脸**：用 `主人公立绘_cutout.png` 的脸部裁切，叠在棺材白纱上；加短促的色差 / 模糊 / 闪白，持续 0.4 秒，再切回。
- **三秒静音**：真的三秒，不放任何声音。
- **案卷**：纸纹 + 打字机字体 + 逐行出现；最后印章用暗红色（`#8B2E2A`），是全片唯一的红。
- **标题卡**：黑底白字，`10:17` 用等宽字体，中文标题用宋体。
- **音效清单**：雨、钟表、门、脚步、室内底噪、烛火、心跳、火柴、吐烟、笔尖、纸张、盖章。大部分可以程序合成；火柴 / 纸张 / 盖章如果合成得不像，再找 CC0。
